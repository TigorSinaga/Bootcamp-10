A CNN-LSTM based audio classification project for automatically recognizing musical chords from digital music segments.

The system uses Mel Spectrogram as the audio representation and combines CNN with Bidirectional LSTM for automatic chord classification.

Technologies
Python CNN BiLSTM Mel Spectrogram Audio Processing
Model Architecture
  • Audio preprocessing
  • Mel Spectrogram extraction
  • TimeDistributed CNN
  • Bidirectional LSTM
  • Softmax classification
  • 24 major/minor chord classes
